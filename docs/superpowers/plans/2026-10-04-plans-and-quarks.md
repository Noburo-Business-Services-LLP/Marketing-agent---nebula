# Plans, Quarks and add-ons Implementation Plan

> **For agentic workers:** Execute task by task (one implementer subagent per task; one final review at the end, as the owner asked for cost reasons). Steps use checkbox syntax.

**Goal:** Free tier (100 Quarks, no expiry, creation only), Starter ₹999 and Professional ₹1,999 plans with Quark allowances, add-on gates, top-up packs, upgrade prompts, and "Quarks" everywhere customer-facing — with the smallest possible change to existing code.

**Spec:** `docs/superpowers/specs/2026-10-04-plans-and-quarks-design.md` (read it first; its tables are the source of numbers).

## Global Constraints

- Change as little existing code as possible; keep current behaviour for existing accounts (they resolve to tier `managed`: nothing blocked, nothing changed).
- Do not rename routes, API fields, DB fields or code identifiers (`credits.balance`, `/credits`, `creditGuard`, etc.): customer-facing text only.
- Do not touch the Kling files (`backend/services/videoService.js`, `routes/videoGeneration.js`, `videoGenerationQueue.js`, `models/VideoJob.js`). Do not change the Hero money path (`heroVideoFlow.js` deduct/create/recheck/submit/refund) except the quota limit lookup.
- No real Razorpay, Ayrshare, Apify, fal or email calls anywhere; tests use fakes. No `.env`, keys, `backend/public` build output or `node_modules` symlinks in commits. Never start servers, never use localhost:5000/:3000 (a real backend and frontend may be listening); no browser unless a task says to use the audit tooling on 127.0.0.1:3100.
- Money maths is in integer paise / integer Quarks (no float drift): ₹999 + 18% GST = 117,882 paise exactly (₹1,178.82); ₹1,999 -> 235,882 paise (₹2,358.82). Round GST to the nearest paisa, half up.
- Prices are GST-exclusive; the app adds 18% at checkout. Starter 2,100 Quarks; Professional 3,500 Quarks; top-up packs ₹999=500, ₹1,999=1,000, ₹4,999=2,500 Quarks (₹2.00 per Quark ex-GST); add-ons Publish and schedule ₹1,000, Competitor insights ₹500, Inbox and automatic replies ₹500 (requires Publish and schedule), bundle ₹1,800 — all in one config so the owner can edit them.
- Keep green: `cd backend && node --test tests/*.test.js` (180 at start; every file must exit by itself), `cd frontend && node --test tests/*.test.mjs` (47+), `cd frontend && npx tsc --noEmit` (exactly 3 pre-existing errors: AdminDashboard, AdminLogin, Influencers). Use nvm for Node (`export NVM_DIR="$HOME/.nvm" && . "$NVM_DIR/nvm.sh"`).
- Voice: customer-facing text follows `docs/superpowers/specs/2026-10-03-nebulaa-app-voice-design.md` (complete, plain, professional sentences; "Quarks"). Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; commit per task; work only in the worktree for branch `nebulaa-redesign`.

## Review Focus (for the one final review)

- An account created before this change, or a managed account, is never blocked by an entitlement check or a Quark/plan rule.
- A free account cannot reach Instagram/social connect, publish, schedule, competitor scraping, inbox or auto-reply through ANY route (including admin-less direct API calls), and gets a plain upgrade message, not a stack trace.
- Webhook idempotency: replaying `subscription.charged` with the same payment id must not grant Quarks twice; unknown plan ids grant nothing; amounts and Quarks come from the config, never from the request body.
- GST maths exact; top-up grants match the pack table and cannot be forged by sending a different amount.
- 7-day expiry gone without leaving a path that locks accounts by time; the 100 Quarks are granted once per account.
- Customer-facing "credits", "trial", "7 days", "free trial" no longer appear (scanner test), while API fields are unchanged.
